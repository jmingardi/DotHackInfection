Experimental Windows x64 build with a graphical launcher.

Download the **Windows-x64.zip**, extract the entire folder, and run
**DotHackInfection.exe**. Select your own supported USA SLUS-20267 ISO in the
launcher. No Python or separate build-tool installation is required; keep all
bundled runtime and compiler files together. New code can compile during play.

Requires Windows x64, .NET Framework 4.8, an AVX2 CPU and compatible graphics
drivers. This portable package uses Windows' FXC shader compiler.

No ISO, extracted retail executable, BIOS, personal save or prefilled gameplay
cache is included. Full campaign compatibility is unverified. Automated build,
launcher and native regression checks do not establish complete-game support.

The source ZIP contains authored project files only. Building it requires your
own supported disc or authorized access to the separately stored private build
inputs. See README.md and docs/GITHUB_RELEASES.md for details.
